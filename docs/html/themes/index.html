Themes

Themes change how the storefront looks. Staff manage them from Online Store → Themes (/admin/themes). A theme is a zip file that staff upload; the app stores it, validates it, and renders storefront pages with it once it is published. Themes never affect the back office.

Themes follow Shopify’s model: a layout wraps every page, each page type has a JSON template listing its sections, and sections can hold blocks. Section and block settings are declared in a schema. Templates are written in Edge.

The store keeps a library of themes. Exactly one is live; the others are unpublished and can be previewed, shared, duplicated, renamed, downloaded or deleted. When no uploaded theme is live, the storefront uses the built-in theme—the React storefront configured from Online Store → Built-in theme.

Use Dawn Lite as the reference: themes/dawn_lite/. Folders in themes/ are added to the library automatically the first time the Themes page loads.
