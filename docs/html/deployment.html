Production deployment

Ship Akinai yourself with the standard AdonisJS production build, or get a consult if you want help designing and running production.

DIY production build

Follow the official AdonisJS deployment guide for the standalone build, how to run it, migrations, static files, logging, and Docker:

https://docs.adonisjs.com/deployment

In short, from the Akinai repo:

yarn build
cd build
yarn install --production
node bin/server.js

On each release, run migrations with node ace migration:run --force (from the build that includes Ace). Configure environment variables on the host—do not ship .env inside the build artifact.

Akinai production requirements

With NODE_ENV=production the app refuses to boot unless:

  • SESSION_DRIVER=database
  • LIMITER_STORE=redis, with REDIS_HOST / REDIS_PASSWORD pointing at Redis
  • S3 (or S3-compatible) storage is configured: AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION, S3_BUCKET (and S3_ENDPOINT when needed)

See also first admin setup, Typesense search, and trusted proxies in the project README.md under Deployment.
