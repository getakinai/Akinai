Run locally and seed demo

Get Akinai running on your machine, then optionally fill the store with demo catalog data so you can click around the storefront and back office.

Quick start

With Node 24+, Yarn and Docker installed:

yarn setup   # install, create .env, start Docker, migrate, seed (clean or demo)
yarn dev     # http://localhost:3333

Then open http://localhost:3333/admin/setup to create your admin account. yarn setup prints the setup token the form asks for (it is also SETUP_TOKEN in .env).

At the seed step, yarn setup asks whether you want a clean store (yarn db:seed) or one with demo products (yarn db:seed:demo). Without an interactive terminal it seeds a clean store. Safe to re-run.

Prerequisites

  • Node.js 24 or newer
  • Yarn classic (npm i -g yarn)
  • Docker (for PostgreSQL, Mailpit, Typesense, Redis)

Manual setup

Use these when you need to run one step on its own. From the getakinai.com repo root:

1. Install and configure

yarn install
cp .env.example .env
node ace generate:key

Set SETUP_TOKEN to 32 or more random characters (for example openssl rand -hex 32). Default database credentials in .env.example match the Docker containers.

2. Start Docker services

yarn docker:up
Service Address
PostgreSQL (app) 127.0.0.1:5432
PostgreSQL (tests) 127.0.0.1:5433
Mailpit SMTP 127.0.0.1:2525
Mailpit inbox UI http://localhost:8025
Typesense http://localhost:8108
Redis 127.0.0.1:6379

Use yarn docker:ps, yarn docker:logs and yarn docker:down to manage them.

3. Migrate and seed

yarn db:migrate
yarn db:seed

yarn db:seed is the minimal setup. It creates store settings, the built-in roles (admin, manager, staff), a default stock location, help center guides, and (in development) a small starter catalog. It does not create staff users.

4. Seed the demo store (optional)

For a fuller catalog to click around in, run the demo seeder after the base seed: 

yarn db:seed:demo

That runs db:seed then node ace seed:demo-store. It adds roughly 100 demo products across collections (Akinai Gadgets), sample product types, vendors, Size/Color options, hero slides, menu links, and related storefront content. Both seeds are safe to re-run; existing records are skipped.

Sync product search after seeding (or whenever the index drifts):

yarn search:sync

5. Start the dev server

yarn dev
  • App: http://localhost:3333
  • Back office: http://localhost:3333/admin/login
  • Storefront signup: http://localhost:3333/signup

6. Create the first admin

While there are no staff users, /admin/login redirects to /admin/setup. Enter the SETUP_TOKEN from .env, the country your store delivers to, and your name, email and password. That creates an admin account and signs you in.

Add more staff later from the back office, or:

node ace create:admin-user

Useful commands

Task Command
Full local bootstrap yarn setup
Dev server yarn dev
Clean store seed yarn db:seed
Demo catalog (after migrate) yarn db:seed:demo
Rebuild DB and seed node ace migration:fresh --seed
Index products in Typesense yarn search:sync
Create a staff user node ace create:admin-user
