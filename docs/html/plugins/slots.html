Plugin slots

A slot is a named placeholder in a storefront template. When an installed plugin declares that slot, it renders there; otherwise the template shows a fallback or nothing.

Available slots

Slots are listed in PLUGIN_SLOTS in app/constants/plugins.ts:

Slot Where it renders
home.hero Top of the home page
home.after_first_rail Home page, below the first product rail
home.footer Home page, below the bottom promo banners
layout.footer Every storefront page, at the top of the site footer
checkout.payment Reserved for payment plugins; not placed in a template yet

Adding a new slot

  1. Add the name to PLUGIN_SLOTS in app/constants/plugins.ts.
  2. Add it to PluginSlotName in inertia/plugins/types.ts. The two lists must match.
  3. Place it in the built-in React template:
<PluginSlot name="home.after_first_rail" />

PluginSlot accepts optional fallback (when no installed plugin fills the slot) and loading (while installed plugins load on client navigation).

Slots in Edge themes

Uploaded themes place slots with the Edge pluginSlot helper, or with Dawn Lite’s plugin_slot section so staff can choose a slot from the template editor: 

{{{ pluginSlot('home.hero', fallbackHtml) }}}

In a JSON template:

"hero_plugin": {
  "type": "plugin_slot",
  "settings": { "slot": "home.hero" }
}

See theme helpers and islands and theme templates for the full Edge context.

Built-in vs theme storefront

  • Built-in theme (React): slots are placed with <PluginSlot /> in Inertia pages such as inertia/pages/home.tsx.
  • Uploaded Edge theme: slots are placed with pluginSlot() or the plugin_slot section. The same plugin key and slot name apply; install state still comes from plugin_installations.

A plugin only shows when it is installed on the server and registered in the client glob. See how plugins load.
