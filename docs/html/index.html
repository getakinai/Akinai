Build and customize Akinai

Akinai is an AdonisJS commerce monolith: a staff back office, a shopper storefront, and optional Edge themes and plugins that change what buyers see. Run it locally first, then read architecture, themes, and plugins.

Run locally yarn setup, yarn dev, and seed a clean or demo store. Understand the architecture How requests move through controllers, services, and Inertia shells. Build a theme Upload Edge sections and templates that render the storefront. Add a plugin Ship optional features that fill named slots on the storefront.

Local setup

Get the app running

Bootstrap with Docker, migrate, seed, and open the back office. Optionally load the Akinai Gadgets demo catalog for a fuller storefront.

Quick start

yarn setup then yarn dev at localhost:3333.

Seed demo data

yarn db:seed:demo for ~100 products and collections.

Install, Docker, migrate, search sync, and first admin setup.

Architecture

How the app is put together

One AdonisJS server renders Inertia page shells and serves a JSON API. Staff and shoppers use separate accounts, URLs, and session guards.

Themes

Build your first theme

A theme is a zip of Edge layouts, JSON templates, and sections—similar to Shopify themes. Staff manage the library from Online Store → Themes. When no theme is live, the built-in React storefront is used.

Plugins

Extend the storefront with plugins

Plugins ship as folders under plugins/. They fill named slots (for example home.hero), register routes and migrations, and can add admin pages—without editing core files by hand.
