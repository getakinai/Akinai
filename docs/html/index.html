Build and customize Akinai

Akinai means “trade” or “commerce” in Japanese (商い), which fits general-purpose selling. It is an AdonisJS commerce monolith: a staff back office, a shopper storefront, and optional Edge themes and plugins that change what buyers see. Run it locally first, then read architecture, themes, and plugins. The source lives on GitHub.

Browse the Storefront and Admin Static snapshots of the storefront and admin from a local demo. Run locally yarn setup, yarn dev, and seed a clean or demo store. Understand the architecture How requests move through controllers, services, and Inertia shells. Build a theme Upload Edge sections and templates that render the storefront. Add a plugin Ship optional features that fill named slots on the storefront. Deploy to production DIY with AdonisJS, or email the Akinai Team for a consult quote.

Architecture

How the app is put together

One AdonisJS server renders Inertia page shells and serves a JSON API. Staff and shoppers use separate accounts, URLs, and session guards.

Themes

Build your first theme

A theme is a zip of Edge layouts, JSON templates, and sections—similar to Shopify themes. Staff manage the library from Online Store → Themes. When no theme is live, the built-in React storefront is used.

Plugins

Extend the storefront with plugins

Plugins ship as folders under plugins/. They fill named slots (for example home.hero), register routes and migrations, and can add admin pages—without editing core files by hand.
